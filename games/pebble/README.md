# 茶点跳跳棋

2026-10-27 批次。原生 Canvas 游戏，复用统一运行器的开始、暂停、重开与全屏行为。

选择一颗茶点，横向或纵向跳过相邻茶点，落到两格外的空位；被跳过的茶点收起。
每盘只留一颗即过关，共三盘；每步 10 分，每盘再奖 100 分。
键盘方向键选格、空格或回车确认；可撤销本盘移动，撤销退回本步得分。180 秒结束。

规则版本 1；同一 seed 可复现题目。测试：npm test -w @playground/game-pebble。

## 递进关卡（版本 1）

人工确定的设计：从 4–16 颗茶点开始，跳跃消除至剩一颗；撤销保留累计步数。共 20 关，每 5 关为入门、熟练、进阶、挑战一个阶段。

通过包的公开 `/campaign` 入口读取固定定义，向 `createGame` 传入可选 `level`；未传时继续使用原普通模式及随机序列。关卡不使用全局倒计时，完成本关目标即可通关。暂停和切到后台时停止计时。

进度按游戏保存在本机，通关解锁下一关。个人最佳先比较步数，再比较用时。普通模式、每日挑战和排行榜继续沿用原规则。固定数据在 `src/campaign-data.js`，生成及真实输入验证工具位于仓库 `scripts/campaigns/`，不把求解器放入浏览器包。

## 普通排行榜

普通模式已接入匿名排行榜，沿用现有计分与最佳成绩规则；提交失败会在有效期内保留并重试。每日挑战日历与每日榜开放状态不变，本游戏每日榜仍未开放。固定关卡进度和成绩仍只保存在本机，不参加排行榜。
