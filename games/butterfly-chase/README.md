# 蝶影寻芳

“蝶影寻芳”是一款约一分钟的追踪反应小游戏。花园中同时飞舞着五只花蝶，先看清上方花笺指定的蝶影，再移动花环捕捉目标；认错蝶影、花环落空或等得太久都会失去一次机会。

## 操作

- 触屏或鼠标：直接轻点目标花蝶，花环会移动到落点并尝试捕捉。
- 键盘：方向键或 WASD 移动花环，空格或回车尝试捕捉。
- 使用页面按钮开始、暂停、继续、重开和切换全屏；窗口尺寸变化时沿用公共运行器的自动暂停行为。

## 计分

- 每捕捉一只指定花蝶得 100 分，连续完成十二轮即以 1200 分通关。
- 每轮寻找时间会逐渐缩短；认错、落空或本轮超时会失去一次机会，并重新布置当前目标。
- 三次机会用完或总时限 75 秒结束；普通模式成绩可进入匿名排行榜。

## 设计约定

- 游戏 ID、包名和存储键固定为 `butterfly-chase` / `@playground/game-butterfly-chase`。
- 每轮的蝶影特征、位置和飞行方向由对局种子与轮次共同决定，同一种子必须可复现。
- 花蝶以颜色和翅纹共同区分，颜色不是唯一提示；移动范围、碰撞半径和计分均属于当前规则的一部分。
- 本游戏暂不加入每日挑战或闯关日历；后续兼容性调整须另行评估。
