# 露珠相逢（dew-links）

批次：2026-11-04，北京时间。普通模式，使用原生 JavaScript、Canvas 2D 和原创 SVG，无新增第三方依赖。

## 玩法与输入

每座 5×5 花圃里有四对带不同纹样的露珠。从一枚露珠出发，只沿上下左右相邻格连接同纹样伙伴；不同小径不能交叉、共用格子或穿过别的露珠。四对露珠全部连接且 25 个格子恰好铺满后进入下一座花圃，共完成三座。

- 手机和鼠标：从露珠按住拖动，经过相邻格铺路；松手可保留未完成小径，再从末端继续。沿原路退回会收短当前小径。
- 键盘：方向键或 WASD 移动选择框，空格或回车从露珠、未完成小径末端开始连线；连线时方向键直接铺路。Z、退格或删除键收起当前格所在小径。
- 从任一端点重新出发会重画该对小径；拖到已有小径或不匹配的露珠时保持原状态并给出具体提示。
- 开始、暂停、继续、重开、转屏暂停和全屏沿用公共运行器；重开保留当前种子。

## 成绩与兼容

150 秒内每铺满一座花圃得 400 分，三座全部完成为 1200 分；超时按已经完整铺满的花圃计分。结果保存得分、用时、完成小径数及完成花圃数。普通匿名排行榜开放，每日榜关闭。

花圃由种子、稳定路线模板及变换生成，所有题面都保留一组可铺满全格的解。新游戏不会改写已发布的每日挑战日历、旧分享链接、规则版本、存档标识或现有 560 个关卡。后续若纳入每日挑战，须按仓库约定另作未来日期的平台变更。

## 设计约定

以晨露、浅米色花圃、柔绿边框和珊瑚、叶绿、桂金、暮紫四条小径延续网站温暖轻松的视觉风格。四对露珠同时使用圆点、菱形、星芒、爱心纹样和颜色识别，不能只依赖颜色。

人工决定：本批次没有新增人工指定设计，不覆盖现有人工内容。

## 验收

单元测试覆盖题面稳定性与完整可解路线、指针和键盘真实铺路、回退、续接、取消、越格、占用冲突、重画、三座完整结算、超时、销毁、快照隔离和成绩防伪。`qa/playthrough.mjs` 使用真实鼠标、键盘和 Chrome 模拟触屏铺满三座花圃，并检查暂停恢复、重开、全屏及八组横竖屏布局。公共验收器负责隔离排行榜、刷新存档、离线及旧游戏回归；触屏模拟不代表实体手机验收。
