# 茶炉候火（tea-timing）

## 玩法

每局需要守候十二壶茶。三只茶壶中每轮只有一只正在加热，蒸汽会标出炉位，底部火候指针从左向右移动。指针进入金色适温区时揭盖即可候好清茶；点错炉、过早揭盖或让指针走到尽头都会失去机会。

## 操作

- 手机 / 平板：轻点左、中、右茶壶。
- 鼠标：点击茶壶。
- 键盘：A、S、D 直接揭开左、中、右炉；也可用左右方向键选择，空格或回车揭盖。
- 页面公共控制提供开始、暂停、继续、重开和全屏；进入全屏、失焦或改变画布尺寸时按运行器约定暂停。

## 计分与结束

- 每候好一壶得 100 分，共十二壶，满分 1200 分。
- 初始三次机会；点错、过早或过火会失去一次，机会用完、本局十二壶处理完或 75 秒到时结算。
- 种子只决定炉位与升温速度，不改变适温区和计分。

## 设计约定

- 仅提供普通模式和普通匿名排行榜，不加入每日挑战或闯关日历。
- 蒸汽、炉位文字和 A/S/D 标记共同提示目标，不只依赖颜色；金色适温区始终带有“适温”文字。
- 暖米色茶室、木质茶台和柔和花园色延续网站风格；画面、图标及插画均由原生 Canvas / SVG 绘制。
- 游戏 ID、包名、存储与分享路由固定为 `tea-timing`；后续不改变已发布计分含义或规则版本。
