# 叶舟托露（leaf-keeper）

批次：2026-11-05，北京时间。动作 / 反应类普通模式，原生 JavaScript / Canvas / 原创 SVG，无新增第三方依赖。

## 玩法与输入

露珠停在叶舟中央，玩家按住一侧让叶片轻轻倾斜，使露珠沿叶面滑向金色花粉光。十二点花粉光左右交替出现，每点限时 4.5 秒；接到一点得 100 分，满分 1200 分。露珠滑出叶沿或追光超时会失去一次机会，接满十二点即通关，三次机会用完或 60 秒结束。

- 手机：按住画布左半边或右半边，移动主指越过中线可直接换向，松开即停。
- 电脑：按住鼠标左右半边；也可按住 ← / → 或 A / D，左右同时按住时停住。
- 暂停 / 继续 / 重开 / 全屏使用公共运行器；暂停、转屏、失焦及全屏切换取消持续输入。重开复用当前种子。
- 花粉位置、方向和成绩由种子及固定步长决定；结算最多一次，销毁不提交成绩。

## 接入与兼容

注册表仅追加本包的公开 manifest、rules、art 与动态 loader，自动接入首页、动手分类、收藏、最近玩过、最佳成绩、分享和隔离普通排行榜验收。无闯关声明，不修改旧游戏、存储标识、560 个已发布关卡、历史每日挑战或规则版本。依照仓库普通模式契约，纳入每日挑战日历需另作平台变更。

## 设计约定

采用浅绿庭院、青绿色叶舟、湖蓝露珠和赭金花粉光，延续网站中文、温暖轻松的短时游玩风格。左右方向由叶片倾斜、画布分区和键盘说明共同传递，剩余时间同时使用进度条，不能只依赖颜色。人工决定：本批次没有新增人工指定设计，不覆盖现有人工内容。

核心是持续按住左右来控制一维滑动、及时刹停并避免叶沿，区别于花径拖线、纸鸢上下飞行、九宫格点灯及风车定点时机玩法；后续调整不改造成点击目标、节奏轨道或固定航道躲避。

## 验收

单元测试覆盖种子目标、左右交替与边界、键盘和指针持续输入、越中线换向、双键、重复键、取消与无效坐标、收集通关、滑落、超时失败、时间步长、成绩规则及销毁隔离。`qa/playthrough.mjs` 使用真实键盘、鼠标与 Chrome 模拟触屏完成十二次追光，并检查暂停恢复、重开、全屏及八种横竖屏布局；公共验收器负责隔离排行榜、刷新存档、离线与旧游戏回归。执行结果以当前提交的 GitHub Actions 记录为准，触屏模拟不代表实体手机验收。
