# 蜂环逐蜜（bee-orbit）

批次：2026-11-13，北京时间。动作／反应类普通模式，原生 JavaScript、Canvas 与原创 SVG，无新增第三方依赖。

## 玩法与输入

小蜜蜂沿双层花环持续顺时针飞行。每座花桥的一环放着金色花粉，另一环悬着蓝色露珠；在抵达花桥前切换到花粉所在的内环或外环。采到十二簇花粉即通关，每簇 100 分，满分 1200 分。碰到露珠会失去一次机会，三次机会用完或 60 秒结束。

- 手机：轻点画布任意位置切换内外环，只响应主指。
- 电脑：点击画布切换；键盘使用空格、回车、方向键上/下或 W/S。
- 暂停、继续、重开与全屏使用公共运行器；暂停、转屏、失焦和全屏切换会停止游戏时钟。重开复用当前种子。
- 花桥顺序、花瓣装饰及成绩由种子和固定步长决定；结算最多一次，销毁不提交成绩。

## 接入与兼容

注册表仅追加本包的公开 manifest、rules、art 与动态 loader，自动接入首页、动手分类、收藏、最近玩过、最佳成绩、分享和隔离普通排行榜验收。无闯关声明，不修改旧游戏、存储标识、560 个已发布关卡、历史每日挑战或规则版本。依照仓库普通模式契约，加入每日挑战须另作平台变更。

## 设计约定

采用浅绿花园、珊瑚色内环、青绿色外环、金色花粉与湖蓝露珠，延续网站中文、温暖轻松的短时游玩风格。花粉与露珠使用形状和文字共同提示，内外环也有不同色彩与标签，不只依赖颜色。

核心是沿圆周持续前进时观察下一座花桥，并用单次输入切换半径；区别于直线固定航道、持续上下飞行、拖线、定点时机和追踪点击玩法。人工决定：本批次没有新增人工指定设计，不覆盖现有人工内容。

## 验收

单元测试覆盖种子花桥、分组平衡、逐步加速、键盘与指针输入、重复键和非法坐标、过桥输入锁定、完整通关、露珠失败、超时、成绩规则及销毁隔离。`qa/playthrough.mjs` 使用真实键盘、鼠标与 Chrome 模拟触屏采完十二簇花粉，并检查暂停恢复、重开、全屏和八种横竖屏布局；公共验收器负责隔离排行榜、刷新存档、离线与旧游戏回归。触屏模拟不代表实体手机验收。
