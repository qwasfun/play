# 花笺逐风

## 玩法

花笺会依次显示上、下、左、右四种风向。在倒计时结束前沿相同方向划动；划错或超时会失去一次机会。完成二十张花笺且仍有机会即通关。

- 每张划对得 100 分，满分 2000 分。
- 共 4 次机会，机会用完或 60 秒到时结束。
- 普通模式开放匿名排行榜；本游戏暂不加入每日挑战和递进关卡。

## 输入

- 手机/平板：在游戏画布上按风向触摸划动。
- 电脑鼠标：按住并沿风向拖划后松开。
- 电脑键盘：方向键或 WASD。
- 短划不提交；暂停、转屏和全屏切换会取消未完成的手势。

## 设计要求与决定

- 这是动作/反应类普通模式游戏，核心是辨认方向并完成手势，不改造成点击按钮、节奏轨道或飞行躲避玩法。
- 方向序列由对局种子生成；每四张恰好包含四个方向，避免某一方向长期缺席。
- 使用原生 Canvas 与原创 SVG，保持暖色纸笺、花瓣和轻松短时游玩风格。
- 游戏 ID、计分字段和普通榜规则发布后保持兼容；每日挑战日历或规则版本调整须另行确认。
