# 松果滑盘

2026-11-27 北京时间批次新增的滑击技巧小游戏。玩家在铺着晨露的叶片滑道上调整方向与力度，把六枚松果送进远处的花环。

## 玩法

- 每局共有六条滑道，每条滑道的花环位置和距离不同。
- 按住松果向后拖，再松手发射；拖动方向决定滑行方向，拖得越远，松果滑得越远。
- 松果停在花心内得 200 分，停在外圈内得 100 分；六次都停进花心可得 1200 分。
- 滑行采用确定性的衰减速度模型，同样的方向与力度会得到同样的落点。

## 输入与兼容

- 触屏或鼠标：从松果按住并向后拖动，松手滑出。
- 键盘：左右键或 A/D 调方向，上下键或 W/S 调力度，空格或回车发射。
- 使用原生 JavaScript、Canvas 与 SVG，不增加运行依赖；沿用现有开始、暂停、继续、重开、全屏、横竖屏、收藏、最近玩过和普通成绩功能。
- 仅开放普通模式排行榜，不改动每日挑战日历、历史规则版本、存档键或既有分享链接。
