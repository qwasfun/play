# 茶席四方（tea-grid）

批次：2026-10-31，北京时间。普通模式，使用原生 JavaScript、Canvas 2D 和原创 SVG，无新增第三方依赖。

## 玩法与输入

在 4×4 茶席中填写青茶、花糕、梅果和月饼。每行、每列以及四个 2×2 小席都要各包含一次四种茶点。连续完成三张确定可解且解唯一的茶席，每张 100 分；180 秒内完成三张通关。

- 手机和鼠标：点空格循环“空白 → 青茶 → 花糕 → 梅果 → 月饼 → 空白”。拖出格子或系统取消不会误填。
- 键盘：方向键或 WASD 选择格子，空格或回车循环茶点；Z、退格键或公共撤销按钮回退一步。
- 固定格不可修改；冲突格使用颜色和文字同时提示。撤销不退回累计步数与时间。
- 开始、暂停、继续、重开、转屏暂停和全屏沿用公共运行器；重开保留当前种子。

## 题目、成绩与兼容

题目由种子、轮次和规则版本稳定生成。基础 4×4 解经过符号、行列带和转置变换，线索位置同步变换；三轮分别保留 10、8、7 个线索。测试会枚举大量种子并用独立求解器确认唯一解。

结果保存得分、完成轮数、累计填写步数和用时。普通匿名排行榜开放，每日榜关闭；新游戏不会改写已发布的每日挑战日历、旧分享链接、规则版本、存档标识或现有 560 个关卡。后续若纳入每日挑战，须按仓库约定另作未来日期的平台变更。

## 设计约定

浅米色茶席配鼠尾草绿、珊瑚粉、暖金和淡紫四种茶点，保持网站温暖轻松的中文风格。每格触控区域为 76×76 逻辑像素；数字、名称和颜色共同表达茶点，不能只依赖颜色。

人工决定：本批次没有新增人工指定设计，不覆盖现有人工内容。

## 验收

单元测试覆盖种子稳定性、唯一解、行列与小席冲突、触屏和键盘输入、取消与拖出、固定格保护、撤销、三轮完整结算、超时、成绩规则与快照隔离。`qa/playthrough.mjs` 使用真实键鼠和 Chrome 触屏输入完成三张茶席，并检查暂停恢复、重开、全屏及八组横竖屏布局。公共验收器负责隔离排行榜、刷新存档、离线及旧游戏回归；触屏模拟不代表实体手机验收。
