# 茶花拈数

2026-11-26 北京时间批次新增的组合策略小游戏。玩家和抱着小竹篮的刺猬轮流从三丛茶花中拈走花瓣，拿到最后一片者赢下一座花园。

## 玩法

- 每局有三座花园，每座花园摆着三丛数量不同的茶花。
- 每次只能选一丛，从中拈走 1–3 片花瓣；小刺猬随后也会走一步。
- 拈走最后一片花瓣者赢下当前花园。赢一座得 400 分，连赢三座可得 1200 分。
- 初始局面都留有必胜策略；观察三丛花瓣余数之间的关系，就能一直把难题留给小刺猬。

## 输入与兼容

- 触屏或鼠标：点一丛茶花、点要拈的数量，再点“放进竹篮”。
- 键盘：左右键或 A/D 选花丛，上下键或 W/S 选数量，空格或回车确认；数字键 1–3 可直选花丛。
- 使用原生 JavaScript、Canvas 与 SVG，不增加运行依赖；沿用现有暂停、继续、重开、全屏、横竖屏、收藏、最近玩过和普通成绩功能。
- 仅开放普通模式排行榜，不改动每日挑战日历、历史规则版本、存档键或既有分享链接。
