# 花溪搭桥

普通模式的短时连桥推理游戏。玩家根据溪石上的数字，在横竖方向最近的溪石之间搭桥，让每块溪石的桥数准确，并让整处溪湾连成一个整体。

## 玩法与操作

- 同一对溪石可搭一座或两座桥，再次操作会拆除；桥不能穿过溪石或彼此交叉。
- 触屏或鼠标依次点两块溪石连接，也可直接点击已有桥；键盘使用方向键或 WASD 选择，空格或回车连接，Z、退格或 Delete 撤销。
- 支持统一的开始、暂停、继续、重开和全屏行为；失焦、调整尺寸及进入全屏时自动暂停。

## 计分

一局包含三处确定性生成的溪湾，每完成一处得 400 分，满分 1200；180 秒到时按已完成溪湾数结算。普通排行榜开放，每日挑战与闯关模式未开放。

## 设计要求

- 保持中文、低压力、暖色花溪风格，逻辑画布为 600 × 480，并兼容手机横竖屏与电脑布局。
- 关卡由固定可解结构按对局种子排序、旋转或翻转；不得依赖网络、第三方资源或其他游戏内部文件。
- 已发布的游戏 ID、计分步长、规则版本及种子生成方式不得无兼容评估修改。
