# 风车采蜜

2026-10-28 批次，规则版本 1。

- 指针旋转到金色花瓣区域时采蜜，每次成功得 50 分。
- 共采 12 次；每次成功后花瓣转移，转速逐渐加快。
- 点早、点晚会扣一次机会，三次失误或 75 秒结束。

输入、暂停及全屏由统一运行器管理；普通模式联网时自动参加普通排行榜，离线成绩保存在本机。

## 递进关卡（版本 1）

人工确定的设计：采蜜命中 4–16 次；目标角度、转速和命中窗口变化。共 20 关，每 5 关为入门、熟练、进阶、挑战一个阶段。

通过包的公开 `/campaign` 入口读取固定定义，向 `createGame` 传入可选 `level`；未传时继续使用原普通模式及随机序列。关卡不使用全局倒计时，按有限路线或事件序列完成目标；保留原生命与失误规则。暂停和切到后台时停止计时。

进度按游戏保存在本机，通关解锁下一关。个人最佳依次比较更少失误、更高得分、更短用时。普通模式、每日挑战和排行榜继续沿用原规则。固定数据在 `src/campaign-data.js`，生成及真实输入验证工具位于仓库 `scripts/campaigns/`，不把求解器放入浏览器包。

## 普通排行榜

普通模式已接入匿名排行榜，沿用现有计分与最佳成绩规则；提交失败会在有效期内保留并重试。每日挑战日历与每日榜开放状态不变，本游戏每日榜仍未开放。关卡进度继续保存在本机；在线通关成绩经服务端操作重放校验后参加逐关榜，不混入总榜。普通成绩与已开放的每日挑战成绩合并计入游戏总榜。
