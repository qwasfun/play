# 花笺折印

普通模式的短时空间推理游戏。玩家观察一张 4×4 花笺如何被对半折叠，以及折好后的打孔位置，再推想完全展开时对称花印会落在哪些格子。

## 玩法与操作

- 按左侧箭头顺序把花笺在心里对半折好；一次折叠留下两个对称花印，两次互相垂直的折叠留下四个。
- 右侧 4×4 花笺是展开后的答案区。点亮所有花印且没有多余标记时，自动进入下一张。
- 触屏或鼠标点击格子；键盘使用方向键或 WASD 移动，空格或回车切换，Z、退格或 Delete 撤销。
- 支持统一的开始、暂停、继续、重开和全屏行为；失焦、调整尺寸及进入全屏时自动暂停。

## 计分

一局包含六张由对局种子确定的折印花笺，前两张折一次、后四张沿互相垂直的方向折两次。每完成一张得 200 分，满分 1200；120 秒到时按已完成张数结算。普通排行榜开放，每日挑战与闯关模式未开放。

## 设计要求

- 保持中文、低压力、暖色手作花笺风格，逻辑画布为 600 × 480，并兼容手机横竖屏与电脑布局。
- 折叠模型追踪每个折后格包含的原始格，保证解答来自真实折叠映射；对局种子只改变方向顺序和打孔位置。
- 使用原生 Canvas 与 SVG，不依赖网络资源、第三方运行依赖或其他游戏内部文件。
- 已发布的游戏 ID、计分步长、规则版本及种子生成方式不得无兼容评估修改。
