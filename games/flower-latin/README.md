# 花格成序（flower-latin）

## 玩法

在 4×4 花格里补上 1–4 四枚花序，让每一行、每一列都恰好包含一次 1、2、3、4。浅色木牌是固定提示，空格可反复切换数字；不需要猜测，每张花笺都有唯一解。

每局依次整理三张花笺，题目与顺序由种子确定。

## 操作

- 手机 / 平板：轻点空格，依次切换空白、1、2、3、4。
- 鼠标：点击空格切换数字。
- 键盘：方向键或 WASD 移动光标，空格或回车切换，Z、退格或 Delete 撤销。
- 页面公共控制提供开始、暂停、继续、重开和全屏；进入全屏、失焦或改变画布尺寸时按运行器约定暂停。

## 计分与结束

- 每完成一张花笺得 400 分，共三张，满分 1200 分。
- 180 秒内完成三张花笺即获胜；到时按已完成花笺数结算。
- 填写次数不扣分，撤销会恢复上一步，计时继续。

## 设计约定

- 仅提供普通模式和普通匿名排行榜，不加入每日挑战或闯关日历。
- 固定提示使用木牌底色与锁点，当前选择使用深色描边，数字也直接表达状态，不只依赖颜色。
- 暖米色花笺、柔和花园色与原生 Canvas / SVG 插画延续网站视觉风格。
- 游戏 ID、包名、存储与分享路由固定为 `flower-latin`；后续不改变已发布生成规则、计分含义或规则版本。
