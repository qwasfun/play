# 微光花径（glow-path）

批次：2026-11-03，北京时间。普通模式，原生 JavaScript / Canvas / 原创 SVG，无新增第三方依赖。

## 玩法与输入

从发光起点按住一枚小萤光，沿米白色花径依次经过八朵路标花；完成三段逐渐变窄的花径即可通关。每朵路标花 50 分，满分 1200 分；碰出花径会回到上一朵路标花并失去一次机会，三次机会用完或 90 秒结束。松手不会扣机会，可停下来重新观察。

- 手机：从萤光处按住并沿花径拖动；只响应主指，松手后可从当前位置继续。
- 电脑：按住鼠标拖动；也可使用方向键或 WASD 连续移动。相反方向同时按住时停住。
- 暂停 / 继续 / 重开 / 全屏使用公共运行器；暂停、转屏、失焦及全屏切换会取消持续输入。重开复用当前种子。
- 三段路线由种子确定；结算最多一次，销毁不提交成绩。

## 接入与兼容

注册表仅追加本包的公开 manifest、rules、art 与动态 loader，自动接入首页、动手分类、收藏、最近玩过、最佳成绩、分享和隔离普通排行榜验收。无闯关声明，不修改旧游戏、存储标识、560 个已发布关卡、历史每日挑战或规则版本。依照仓库普通模式契约，纳入每日挑战日历需另作平台变更。

## 设计约定

以浅绿庭院、米白花径、金色微光和珊瑚色小花保持网站温暖轻松的视觉风格。路线宽度、虚线中心和编号路标同时表达边界与进度，不能只依赖颜色。指针移动按短线段连续检查，不能跨过花径或跳过路标。人工决定：本批次没有新增人工指定设计，不覆盖现有人工内容。

## 验收

单元测试覆盖种子路线、边界几何、指针与键盘连续输入、取消和无效输入、碰沿复位、完整通关、失败结算、时间步长、成绩规则及快照隔离。`qa/playthrough.mjs` 使用真实鼠标、键盘和 Chrome 模拟触屏走完三段路线，并检查暂停恢复、重开、全屏及横竖屏布局；公共验收器负责隔离排行榜、刷新存档、离线与旧游戏回归。执行结果以当前提交的 GitHub Actions 记录为准，触屏模拟不代表实体手机验收。
