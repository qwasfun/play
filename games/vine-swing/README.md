# 藤蔓轻荡（vine-swing）

批次：2026-11-17，北京时间。动作／反应类普通模式，原生 JavaScript、Canvas 与原创 SVG，无新增第三方依赖。

## 玩法与输入

小种子挂在花藤下左右摆动。看清下一朵花的方向，等金色微光靠近中央时松手，借着摆速飞向下一根花藤；完成十次接力即通关。每次接力 120 分，满分 1200 分。松手过早或过晚会掉进花瓣软垫并失去一次机会，三次机会用完或 75 秒结束。

- 手机 / 平板：轻点游戏画布松开花藤，只响应主指。
- 鼠标：点击游戏画布松藤。
- 键盘：空格、回车、↑ 或 W 松藤；按键重复不会重复释放。
- 暂停、继续、重开与全屏使用公共运行器；暂停、转屏、失焦和全屏切换会停止游戏时钟。重开复用当前种子。
- 花藤位置、藤长、花瓣装饰和摆荡方向由种子确定；结算最多一次，销毁不提交成绩。

## 接入与兼容

注册表仅追加本包的公开 manifest、rules、art 与动态 loader，自动接入首页、动手分类、收藏、最近玩过、最佳成绩、分享和隔离普通排行榜验收。无闯关声明，不修改旧游戏、存储标识、560 个已发布关卡、历史每日挑战或规则版本。依照仓库普通模式契约，加入每日挑战须另作平台变更。

## 设计约定

采用浅绿晨雾、藤蔓、珊瑚花与金色松手提示，延续网站中文、温暖轻松的短时游玩风格。目标方向同时使用花朵位置、箭头、文字和金色状态表达，不只依赖颜色。

核心是观察连续摆荡的相位与目标方向，在合适时机由附着状态切换为抛物飞行；区别于固定轨道换环、四向目标反应、原地计时揭盖、持续移动闪避和单次蓄力搭桥玩法。人工决定：本批次没有新增人工指定设计，不覆盖现有人工内容。

## 验收

单元测试覆盖种子花藤、边界与左右变化、逐步收紧的松手窗口、相位距离、键盘与指针输入、按键重复和非法坐标、飞行与回落阶段输入锁定、完整通关、失误与超时失败、成绩规则及销毁隔离。`qa/playthrough.mjs` 使用真实键盘、鼠标与 Chrome 模拟触屏完成十次接力，并检查暂停恢复、重开、全屏和八种横竖屏布局；公共验收器负责隔离排行榜、刷新存档、离线与旧游戏回归。触屏模拟不代表实体手机验收。
