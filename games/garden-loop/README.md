# 花篱成环（garden-loop）

批次：2026-11-08，北京时间。普通模式，使用原生 JavaScript、Canvas 2D 和原创 SVG，无新增第三方依赖。

## 玩法与输入

每座 4×4 花圃的数字表示所在花格四周需要几段篱笆。玩家切换格线上的篱边，让所有数字同时满足，并让全部篱笆首尾相接，围成一条不分叉、不断开、也不分成多个小圈的闭环。完成一座后进入下一座，共三座。

- 手机和鼠标：点按花格边缘切换一段篱笆。
- 键盘：方向键或 WASD 在篱边之间移动选择圈，空格或回车切换当前篱边；Z、退格或删除键撤销上一步。
- 公共工具栏的撤销按钮也可回退；开始、暂停、继续、重开、转屏暂停和全屏沿用公共运行器，重开保留当前种子。
- 数字变绿表示当前四周段数刚好，变红表示已经超出，帮助玩家及时修正但不会自动代解。

## 成绩与兼容

180 秒内每围好一座花圃得 400 分，三座全部完成为 1200 分；超时按已经完整围好的花圃计分。结算保存得分、用时和完成花圃数。普通匿名排行榜开放，每日榜关闭。

题面由种子、三组稳定闭环模板及旋转、镜像变换生成；每一题都随包携带一组可验证的完整解。新游戏不会改写已发布的每日挑战日历、旧分享链接、规则版本、存档标识或现有 560 个关卡。后续若纳入每日挑战，须按仓库约定另作未来日期的平台变更。

## 设计约定

以浅米色花格、柔绿花篱、桂金小花和木色篱桩延续网站温暖轻松的视觉风格。数字状态同时使用颜色和段数逻辑表达；选中篱边有虚线圆圈，不能只依赖颜色辨认。

人工决定：本批次没有新增人工指定设计，不覆盖现有人工内容。

## 验收

单元测试覆盖题面稳定性和变换、完整可解闭环、开环、分叉、多圈及数字冲突判定、真实指针输入、键盘移动和落篱、撤销、无效输入、三座完整结算、超时、销毁、快照隔离和成绩防伪。`qa/playthrough.mjs` 使用真实鼠标、键盘和 Chrome 模拟触屏完成三座花圃，并检查暂停恢复、重开、全屏及八组横竖屏布局。公共验收器负责隔离排行榜、刷新存档、离线及旧游戏回归；触屏模拟不代表实体手机验收。
