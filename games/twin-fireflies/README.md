# 双萤穿花

两只萤火虫会并肩向花园深处飞去。观察前方双花门的间距，及时收拢或展开队形，让两只萤火虫同时穿过各自的花环。

## 玩法

- 每局共有 12 道双花门，花门会沿花径逐渐靠近。
- 轻点左半边收拢双萤，轻点右半边展开双萤；每次移动一档。
- 花门抵达时，两只萤火虫都落在花环内即穿越成功；错过会失去一片护叶。
- 三片护叶用完、12 道花门结束或 50 秒到时，本局结束。

## 操作

- 手机与平板：轻点画布左半边收拢，轻点右半边展开。
- 鼠标：点击画布左、右半边调整间距。
- 键盘：`←` / `A` 收拢，`→` / `D` 展开。

页面公共控件提供开始、暂停、继续、重开与全屏；切换全屏或屏幕尺寸变化时会自动暂停。

## 计分

每穿过一道双花门得 100 分，12 道全部通过即获满分 1200。普通模式成绩可参加休闲排行榜；本游戏不加入既有每日挑战日历。

## 设计要求与人工决定

- 使用原生 JavaScript、Canvas 2D 与原创 SVG，不引入额外运行依赖或外部素材。
- 玩法核心是同时控制两个对称角色的间距，不改成单角色闪避或单点时机玩法。
- 固定五档间距与种子生成的花门顺序必须保持可复现，便于成绩校验与完整游玩验收。
