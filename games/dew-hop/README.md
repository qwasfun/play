# 露珠跳荷（dew-hop）

批次：2026-11-15，北京时间。动作／反应类普通模式，原生 JavaScript、Canvas 与原创 SVG，无新增第三方依赖。

## 玩法与输入

小露珠停在池心，四方荷叶会轮流亮起金色花蕊。看清目标后，在涟漪收拢前跳向对应方向；连续完成十二跳即通关。每跳 100 分，满分 1200 分。点错荷叶或等待过久会失去一次机会，三次机会用完或 60 秒结束。

- 手机 / 平板：轻点亮起花蕊的荷叶，只响应主指。
- 鼠标：点击目标荷叶。
- 键盘：方向键或 WASD 跳向上、右、下、左；按键重复不会多跳。
- 暂停、继续、重开与全屏使用公共运行器；暂停、转屏、失焦和全屏切换会停止游戏时钟。重开复用当前种子。
- 荷叶方向、叶纹装饰与成绩由种子和固定步长决定；结算最多一次，销毁不提交成绩。

## 接入与兼容

注册表仅追加本包的公开 manifest、rules、art 与动态 loader，自动接入首页、动手分类、收藏、最近玩过、最佳成绩、分享和隔离普通排行榜验收。无闯关声明，不修改旧游戏、存储标识、560 个已发布关卡、历史每日挑战或规则版本。依照仓库普通模式契约，加入每日挑战须另作平台变更。

## 设计约定

采用浅蓝池水、嫩绿荷叶、金色目标花蕊与珊瑚色提示，延续网站中文、温暖轻松的短时游玩风格。目标同时使用花蕊、文字与方向箭头表达，不只依赖颜色。

核心是观察四方离散目标并立即选择对应空间方向；区别于持续移动追踪、固定轨道切换、单点时机、手势方向卡和自由点击目标玩法。人工决定：本批次没有新增人工指定设计，不覆盖现有人工内容。

## 验收

单元测试覆盖种子方向、分组平衡、逐步收紧的反应窗口、四向键盘与荷叶点击、按键重复和非法坐标、提示与跳跃阶段输入锁定、完整通关、点错与超时失败、成绩规则及销毁隔离。`qa/playthrough.mjs` 使用真实键盘、鼠标与 Chrome 模拟触屏完成十二跳，并检查暂停恢复、重开、全屏和八种横竖屏布局；公共验收器负责隔离排行榜、刷新存档、离线与旧游戏回归。触屏模拟不代表实体手机验收。
