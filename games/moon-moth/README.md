# 月蛾追光（moon-moth）

批次：2026-11-23，北京时间。动作／反应类普通模式，原生 JavaScript、Canvas 与原创 SVG，无新增第三方依赖。

## 玩法与输入

月蛾沿三条花径飞行，每道迎面而来的光门只有一条花径亮着暖黄花灯，另外两条会漫起冷雾。在光门抵达前换到亮灯花径，连续追上十五盏暖灯即通关。每盏 100 分，满分 1500 分；撞上冷雾会失去一片护叶，三片用完或 50 秒结束。

- 手机 / 平板：轻点任意花径直接换轨，只响应主指。
- 鼠标：点击对应花径。
- 键盘：`↑` / `↓` 或 `W` / `S` 逐条移动。
- 暂停、继续、重开与全屏使用公共运行器；暂停、转屏、失焦和全屏切换会停止游戏时钟。重开复用当前种子。
- 光门顺序、亮灯花径、花灯纹样及成绩由种子和固定步长确定；结算最多一次，销毁不提交成绩。

## 接入与兼容

注册表仅追加本包的公开 manifest、rules、art 与动态 loader，自动接入首页、动手分类、收藏、最近玩过、最佳成绩、分享和隔离普通排行榜验收。无闯关声明，不修改旧游戏、存储标识、560 个已发布关卡、历史每日挑战或规则版本。依照仓库普通模式契约，加入每日挑战须另作平台变更。

## 设计约定

采用柔灰月夜、浅绿花径、暖金花灯、冷蓝薄雾和原创月蛾形象，延续网站中文、温暖轻松的短时游玩风格。正确路线同时使用发光花朵造型、位置和文字反馈表达，不只依赖颜色。

核心是在连续前进的三轨光门中提前观察、直接换轨并保持位置；区别于追踪交换物体、双角色间距、连续摆荡、单点时机、固定方向提示与自由移动闪避。人工决定：本批次没有新增人工指定设计，不覆盖现有人工内容。

## 验收

单元测试覆盖种子光门、三轨覆盖、键盘逐轨、宽触控区域与边界、完整通关、撞雾失败、异常时间、成绩规则及销毁隔离。`qa/playthrough.mjs` 使用真实键盘、鼠标与 Chrome 模拟触屏完成十五道光门，并检查暂停恢复、重开、全屏和八种横竖屏布局；公共验收器负责隔离排行榜、刷新存档、离线与旧游戏回归。触屏模拟不代表实体手机验收。
