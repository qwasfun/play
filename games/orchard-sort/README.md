# 果园分篮 · 2026-10-29 批次

借用空篮周转，把苹果、橘子、青梨分别归入满篮，余下一篮留空。四篮各容三颗，每次仅搬动篮顶一颗，目标篮有空位即可放入（不要求同色）。共三盘，180 秒；每盘 100 分，完成三盘通关，超时保留已完成盘得分。相同种子生成相同可解盘面。

触屏/鼠标：点源篮，再点目标篮；同篮取消。键盘：左右/A/D 选择，空格或 Enter 操作，Z/Backspace 撤销。撤销不退步数和时间，不能跨盘撤销。统一运行器负责开始、暂停/继续、重开、全屏、失焦与旋转保护、结束、成绩及排行榜。普通模式接入首页分类、收藏、最近玩过、离线包和本机存档。

设计要求：暖奶油底、藤篮与原创水果插画；水果同时显示文字，不单靠颜色辨认。篮位宽大便于触屏操作。独立的栈顶归类玩法，不改动已有游戏或公共接口。
