# 花轮接露

## 玩法

四色花轮守在晨光中央，露珠会从上、右、下、左四个方向依次靠近。看清露珠颜色，在它抵达花轮前向左或向右旋转，让入口方向上的花瓣与露珠同色。接住二十颗露珠即完成游戏。

每颗露珠接住得 60 分，满分 1200 分。接错颜色或没有及时转到正确花瓣会失去一次机会；三次机会用完或 75 秒结束。

## 操作

- 手机或鼠标：轻点画布左半边向左旋转，轻点右半边向右旋转。
- 键盘：方向键左/右或 A/D 旋转花轮。
- 使用页面上的公共按钮开始、暂停、继续、重开及切换全屏。

## 设计要求

- 保持中文、温暖、轻松的花园视觉，以原生 Canvas 绘制花轮、露珠与晨光。
- 四种颜色同时使用不同花瓣纹样，避免只依赖色觉判断。
- 普通模式使用确定种子生成露珠次序；不加入每日挑战或闯关日历。
- 计分、生命、倒计时和结束状态须能由服务端规则独立校验。
