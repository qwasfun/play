# 花洒浇园

2026-11-25 北京时间批次新增的动作反应小游戏。玩家转动花圃中央的花洒，在金色水滴收拢前浇到八个方位中亮起的花盆。

## 玩法

- 每局依次出现十二盆缺水小花，位置由种子确定且不会连续重复。
- 触屏或鼠标直接点亮起的花盆；键盘左右键或 A/D 转向，空格或回车喷水。
- 每盆 100 分，浇开十二盆得 1200 分；喷错或超时会失去一片叶子，三片用完结束。
- 响应时间会从 2.65 秒逐步收紧至 1.44 秒，保持约一分钟的轻快节奏。

## 设计与兼容

- 使用原生 JavaScript、Canvas 与 SVG，不增加运行依赖。
- 鼠标、键盘和触屏共享同一输入语义，横竖屏和全屏由现有运行器适配。
- 仅开放普通模式排行榜，不改动每日挑战日历、历史规则版本、存档键或既有分享链接。
