# 花圃分畦

2026-11-28 北京时间批次新增的分区逻辑小游戏。玩家把 5×5 花圃划成一块块矩形花畦，让每块花畦恰好包住一枚数字花牌，且格数与花牌数字相同。

## 玩法

- 每局依次整理三座花圃，每座花圃由五块矩形花畦铺满。
- 从一个格子拖到另一个格子可框出矩形；矩形必须恰含一枚花牌，面积也必须等于牌上的数字。
- 已落下的花畦不能重叠；可随时撤销上一块，整座花圃铺满后得 400 分，三座共 1200 分。
- 题面由固定可验证的矩形模板经过旋转、镜像及花牌位置变化生成；同一随机种子始终得到同一组题目。

## 输入与兼容

- 触屏或鼠标：从矩形一角拖到对角并松手。
- 键盘：方向键或 WASD 移动光标，空格或回车确定第一角与对角，Z、退格或 Delete 撤销。
- 使用原生 JavaScript、Canvas 与 SVG，不增加运行依赖；沿用现有开始、暂停、继续、重开、全屏、横竖屏、收藏、最近玩过和普通成绩功能。
