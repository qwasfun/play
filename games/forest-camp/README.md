# 林间安帐

普通模式的短时营地逻辑游戏。玩家根据林地四周的行列数字，在每棵小树旁搭一顶帐篷；帐篷之间不能相邻，让三处林间营地安静地亮起灯火。

## 玩法与操作

- 每顶帐篷必须与一棵树上下或左右相邻，并与树一一配对；帐篷之间横、竖、斜方向都不能接触。
- 林地上方与右侧的数字分别表示每列、每行应有的帐篷数。点空地会依次切换帐篷、草叶标记和留空。
- 触屏或鼠标点击格子；键盘使用方向键或 WASD 移动，空格或回车切换，Z、退格或 Delete 撤销。
- 支持统一的开始、暂停、继续、重开和全屏行为；失焦、调整尺寸及进入全屏时自动暂停。

## 计分

一局包含三张由对局种子确定的唯一解营地图，每完成一张得 400 分，满分 1200；180 秒到时按已完成营地图数结算。普通排行榜开放，每日挑战与闯关模式未开放。

## 设计要求

- 保持中文、低压力、暖色林间露营风格，逻辑画布为 600 × 480，并兼容手机横竖屏与电脑布局。
- 三张基础营地图均通过规则求解器验证唯一解；对局种子只改变顺序、旋转和镜像，不改变可解性。
- 使用原生 Canvas 与 SVG，不依赖网络资源、第三方运行依赖或其他游戏内部文件。
- 已发布的游戏 ID、计分步长、规则版本及种子变换方式不得无兼容评估修改。
