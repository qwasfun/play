# 花钿入匣

“花钿入匣”是一款约两到三分钟的空间拼装小游戏。每只 5×5 花匣要放入五枚各占五格的花钿；花钿可以旋转、拾回和重新放置，全部 25 格恰好铺满才算完成。三只花匣的分区形状逐步变化，既要看清形状，也要安排彼此的位置。

## 操作

- 触屏或鼠标：点选花钿，点“旋转”调整方向，再点花匣格子放置；点已放置的花钿可拾回。
- 键盘：上下方向键选择花钿，空格或回车拿起；方向键移动落点，R 旋转，空格或回车放置，Esc 返回花钿栏。
- Z、退格键或页面“撤销”按钮可回退最近一次拾取、旋转或放置；步数和计时不会回退。
- 使用页面按钮开始、暂停、继续、重开和切换全屏；窗口尺寸变化时沿用公共运行器的自动暂停行为。

## 计分

- 每装满一只花匣得 400 分，三匣满分 1200 分。
- 总时限 180 秒；时间结束时按已经完整装好的花匣结算。
- 普通模式成绩可进入匿名排行榜；本游戏暂不加入每日挑战或闯关日历。

## 设计约定

- 游戏 ID、包名和存储键固定为 `petal-packing` / `@playground/game-petal-packing`。
- 花匣分区由种子确定整体旋转、镜像、花钿顺序和初始方向；同一种子必须可复现。
- 五枚花钿都由五个边相连方格组成，解答只允许旋转，不允许翻面；放置必须在花匣内且不能重叠。
- 当前计分版本固定为每匣 400 分、三匣 1200 分、180 秒时限。计分、题面或模式兼容性调整须另行评估。
