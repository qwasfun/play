# 花镜引光

## 玩法

晨光从花圃边缘照入。旋转格子里的斜镜，让光束依次照亮所有花朵，并从挂着金色风铃的出口离开。每局包含三座 5×5 花圃，镜片位置固定、方向可切换；题目随对局种子旋转和排序，但每题都有唯一解。

## 输入

- 手机、平板和鼠标：轻点镜片旋转。
- 键盘：方向键或 WASD 选择镜片，空格或回车旋转；Z、退格或 Delete 撤销。
- 使用游乐场统一的开始、暂停、继续、重开和全屏按钮；尺寸或方向变化时自动暂停。

## 计分

每完成一座花圃得 400 分，共三座、满分 1200。180 秒到时结束，按已经完成的花圃数量结算。

## 设计说明

这是普通模式的光路推理游戏。核心是预判 `/` 与 `\\` 两类镜面的反射方向，不复制数独、数织、连线、排序、拼块或追踪反应玩法。画面、图标和插画均由原生 Canvas / SVG 绘制，不使用外部素材或新增运行依赖。2026-11-16 批次只接入普通模式，不修改每日挑战日历、历史分享链接或规则版本映射。
