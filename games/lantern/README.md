# 萤灯巡夜

2026-10-27 批次。原生 Canvas 游戏，复用统一运行器的开始、暂停、重开与全屏行为。

九格中每轮只有一盏萤灯；等它亮成金色再点击，灰色小花不要碰。
每轮预告 0.6 秒，亮灯 0.9 秒，共 24 轮；亮灯命中得 25 分。
漏接或点错扣一次机会，三次失误结束；方向键选格，空格或回车点灯。

规则版本 1；同一 seed 可复现题目。测试：npm test -w @playground/game-lantern。

## 递进关卡（版本 1）

人工确定的设计：点亮 6–28 盏灯；位置变化，预告和亮灯时间逐步缩短。共 20 关，每 5 关为入门、熟练、进阶、挑战一个阶段。

通过包的公开 `/campaign` 入口读取固定定义，向 `createGame` 传入可选 `level`；未传时继续使用原普通模式及随机序列。关卡不使用全局倒计时，按有限路线或事件序列完成目标；保留原生命与失误规则。暂停和切到后台时停止计时。

进度按游戏保存在本机，通关解锁下一关。个人最佳依次比较更少失误、更高得分、更短用时。普通模式、每日挑战和排行榜继续沿用原规则。固定数据在 `src/campaign-data.js`，生成及真实输入验证工具位于仓库 `scripts/campaigns/`，不把求解器放入浏览器包。

## 普通排行榜

普通模式已接入匿名排行榜，沿用现有计分与最佳成绩规则；提交失败会在有效期内保留并重试。每日挑战日历与每日榜开放状态不变，本游戏每日榜仍未开放。固定关卡进度和成绩仍只保存在本机，不参加排行榜。
