# 花窗点彩（flower-picross）

## 玩法

根据花窗左侧与上方的数字提示，在 5×5 方格中点亮连续的花瓣格。每个数字表示该行或该列一段连续花瓣的长度；同一条线上有多个数字时，各段之间至少隔一个空格。让点亮的方格与全部提示相符，即可完成花窗。

每局依次完成三扇花窗，图案与顺序由种子确定。所有图案均有唯一解，不需要猜测。

## 操作

- 手机 / 平板：轻点方格，在空白与花瓣之间切换。
- 鼠标：点击方格切换。
- 键盘：方向键或 WASD 移动光标，空格或回车切换方格，Z、退格或 Delete 撤销。
- 页面公共控制提供开始、暂停、继续、重开和全屏；进入全屏、失焦或改变画布尺寸时按运行器约定暂停。

## 计分与结束

- 每完成一扇花窗得 400 分，共三扇，满分 1200 分。
- 180 秒内完成三扇花窗即获胜；到时按已完成花窗结算。
- 落笔次数不扣分，撤销会恢复上一步，计时继续。

## 设计约定

- 仅提供普通模式和普通匿名排行榜，不加入每日挑战或闯关日历。
- 数字提示、花瓣填充和光标描边同时传达状态，不只依赖颜色。
- 暖米色木窗、柔和花园色与原生 Canvas / SVG 插画延续网站视觉风格。
- 游戏 ID、包名、存储与分享路由固定为 `flower-picross`；后续不改变已发布图案、计分含义或规则版本。
