# 纸鸢乘风（kite）

批次：2026-10-30，北京时间。普通模式，原生 JavaScript / Canvas / 原创 SVG，无新增第三方依赖。

## 玩法与输入

纸鸢自动向前，玩家连续控制高度，在花环中心抵达纸鸢时让整个纸鸢进入开口。花环连续上下轻摆，区别于离散航道选择、单次起跳或时机点击。十二道花环，每道 100 分；走完全程且穿过至少十道通关，三次错过或 60 秒结束。

- 手机：按住画布上半区升高、下半区降低，移动手指可切换方向，松开即停；只响应主指。
- 电脑：↑ / W 升高，↓ / S 降低，或鼠标按住画布上下区域；相反方向同时按住时停住。
- 暂停 / 继续 / 重开 / 全屏使用公共运行器；暂停、转屏、失焦及全屏切换取消持续输入。重开复用当前种子。
- 花环、位置及分数由种子和固定步长决定；结算最多一次，销毁不提交成绩。

## 接入与兼容

注册表仅追加该包的公开 manifest、rules、art 与 loader，自动接入首页、动手分类、收藏、最近玩过、最佳成绩、分享及隔离榜单验收。无闯关声明，不修改旧游戏、存储标识、560 个已发布关卡、历史每日挑战和规则版本。按仓库既有普通模式契约，纳入每日挑战日历需另作平台变更。

## 设计约定

采用浅绿天空、米白云朵、珊瑚色纸鸢和赭金花环，保持中文、温暖短时游玩风格。上下操控区各占半块画布；开口与序号同时传递目标，不能只依赖颜色。飞行高度有边界，不因碰到画布边缘扣机会。人工决定：本批次没有新增人工指定设计，不覆盖现有人工内容。

## 验收

单元测试覆盖种子与可达性、连续升降、双键、重复键、指针取消及越界、完整通关与失败结算、时间步长、成绩规则及快照隔离。`qa/playthrough.mjs` 使用真实键鼠和 Chrome 触屏输入飞完全程，并检查暂停恢复、重开、全屏及横竖屏布局；公共验收器负责隔离榜单、刷新存档、离线与旧游戏回归。执行结果以当前提交的 GitHub Actions 记录为准，触屏模拟不代表实体手机验收。
