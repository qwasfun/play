# 花影叠窗

2026-11-24 北京时间批次新增的益智小游戏。玩家旋转三层不同形状的透明花叶模板，使它们叠加后的 4×4 覆盖数字与目标花窗一致。

## 玩法

- 每局四扇花窗，每扇花窗都有唯一的三层旋转组合。
- 点按模板可顺时针旋转 90°；左侧显示当前叠影，右侧显示目标覆盖数。
- 键盘左右键选择模板，空格或回车旋转，Z、退格或 Delete 撤销。
- 每扇花窗 300 分，四扇全部完成得 1200 分；150 秒到时结束。

## 设计与兼容

- 使用原生 JavaScript、Canvas 与 SVG，不增加运行依赖。
- 鼠标、键盘和触屏共用同一套输入语义，横竖屏和全屏由现有运行器适配。
- 仅开放普通模式排行榜，不改动每日挑战日历、历史规则版本、存档键或既有分享链接。
- 题目由种子确定，穷举 64 种旋转组合后只选择唯一解目标。
