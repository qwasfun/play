# 风铃排音（chime-order）

## 玩法

每局包含三段旋律。画面上方悬着六枚标有 1–6 音高的风铃，下方显示目标旋律的高低剪影。依次选择两枚风铃交换位置，使六枚风铃从左到右与剪影完全一致。排好一段后自动进入下一段。

## 操作

- 手机 / 平板：依次轻点两枚风铃交换。
- 鼠标：依次点击两枚风铃交换。
- 键盘：左右方向键或 A/D 选择，空格或回车拿起、放下；Z、退格或 Delete 撤销，Esc 取消选择。
- 页面公共控制提供开始、暂停、继续、重开和全屏；进入全屏、失焦或改变画布尺寸时按运行器约定暂停。

## 计分与结束

- 每完成一段旋律得 400 分，共三段，满分 1200 分。
- 150 秒内排完三段即获胜；时间耗尽时按已完成段数结算。
- 交换次数会显示但不扣分。种子只决定各段的目标顺序与初始乱序。

## 设计约定

- 仅提供普通模式和普通匿名排行榜，不加入每日挑战或闯关日历。
- 风铃用颜色、长度和 1–6 数字共同表达音高，不能只依赖颜色辨认。
- 暖米色庭院、木绳与柔和花园色延续站点轻松风格；画面、图标和插画均由原生 Canvas / SVG 绘制。
- 游戏 ID、包名、存储与分享路由固定为 `chime-order`；后续不改变已发布的计分含义或规则版本。
