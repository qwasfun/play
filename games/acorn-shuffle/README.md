# 叶篮寻果（acorn-shuffle）

批次：2026-11-21，北京时间。动作／反应类普通模式，原生 JavaScript、Canvas 与原创 SVG，无新增第三方依赖。

## 玩法与输入

三只叶篮排在林间。每轮先看清金色橡果藏进哪只叶篮；叶篮盖好后会连续交换位置，始终盯住藏果的那只，交换停止后把它找出来。连续找对十二轮即通关。每轮 100 分，满分 1200 分；选错或超时会失去一片护叶，三片用完或 70 秒结束。

- 手机 / 平板：轻点要选择的叶篮，只响应主指。
- 鼠标：点击对应叶篮。
- 键盘：`←` / `→` 或 `A` / `D` 移动选择，空格或回车确认；也可按 `1`、`2`、`3` 直接选择。
- 暂停、继续、重开与全屏使用公共运行器；暂停、转屏、失焦和全屏切换会停止游戏时钟。重开复用当前种子。
- 初始藏果位置、交换路径、叶片纹样及成绩由种子和固定步长确定；结算最多一次，销毁不提交成绩。

## 接入与兼容

注册表仅追加本包的公开 manifest、rules、art 与动态 loader，自动接入首页、动手分类、收藏、最近玩过、最佳成绩、分享和隔离普通排行榜验收。无闯关声明，不修改旧游戏、存储标识、560 个已发布关卡、历史每日挑战或规则版本。依照仓库普通模式契约，加入每日挑战须另作平台变更。

## 设计约定

采用浅绿林地、编织叶篮、金色橡果和柔和交换轨迹，延续网站中文、温暖轻松的短时游玩风格。选中位置同时使用金色外圈、数字和文字表达，不只依赖颜色。

核心是连续追踪会相互换位的多个移动对象，并在运动停止后作答；区别于固定航道换位、方向提示反应、节奏点击、单点时机、记忆序列和持续移动闪避。人工决定：本批次没有新增人工指定设计，不覆盖现有人工内容。

## 验收

单元测试覆盖种子轮次、交换路径与最终位置、逐轮加速、键盘选择与数字直选、指针边界、非作答阶段输入锁定、完整通关、错选与超时失败、成绩规则及销毁隔离。`qa/playthrough.mjs` 使用真实键盘、鼠标与 Chrome 模拟触屏完成十二轮，并检查暂停恢复、重开、全屏和八种横竖屏布局；公共验收器负责隔离排行榜、刷新存档、离线与旧游戏回归。触屏模拟不代表实体手机验收。
