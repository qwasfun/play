# 花房暗语（garden-code）

批次：2026-11-02，北京时间。普通模式，使用原生 JavaScript、Canvas 2D 和原创 SVG，无新增第三方依赖。

## 玩法与输入

暗语由桃、梅、兰、桂、竹五种花印中的四枚组成，允许重复，但每局至少出现三种。玩家提交猜测后，实心点表示花印与位置都正确，空心点表示花印正确但位置不对；提示不对应某个具体格子。180 秒内最多猜八次。

- 手机和鼠标：先点需要修改的格子，再点花印；也可连续点四枚花印自动前进。点“提交花笺”验证。
- 键盘：左右方向键或 A/D 选择格子，上下方向键、W/S 或空格循环花印；回车提交，退格清空当前格。
- 不完整的花笺不会提交，也不消耗猜测次数；拖出按钮、系统取消或重复按键不会误操作。
- 开始、暂停、继续、重开、转屏暂停和全屏沿用公共运行器；重开保留当前种子。

## 成绩与兼容

第一次猜中得 1000 分，此后每多使用一次猜测扣 100 分，第八次猜中得 300 分；超时或八次均未猜中为 0 分。结果保存得分、用时、猜测次数及最终位置正确数。普通匿名排行榜开放，每日榜关闭。

暗语由种子与规则版本稳定生成。新游戏不会改写已发布的每日挑战日历、旧分享链接、规则版本、存档标识或现有 560 个关卡。后续若纳入每日挑战，须按仓库约定另作未来日期的平台变更。

## 设计约定

浅米色花笺配桃红、梅紫、兰绿、桂金和竹青五枚原创花印，沿用网站温暖轻松的中文风格。花印同时使用文字和颜色表达，反馈同时使用实心、空心形状与数字，不能只依赖颜色。

人工决定：本批次没有新增人工指定设计，不覆盖现有人工内容。

## 验收

单元测试覆盖暗语稳定性与多样性、重复花印反馈、触屏和键盘输入、取消与拖出、不完整提交、快照隔离、八次失败、超时、完整结算和成绩防伪。`qa/playthrough.mjs` 使用真实键盘和 Chrome 触屏输入完成一局，并检查暂停恢复、重开、全屏及八组横竖屏布局。公共验收器负责隔离排行榜、刷新存档、离线及旧游戏回归；触屏模拟不代表实体手机验收。
